# Tango Gift Hunter — онлайн-панель с автосинхронизацией

Адрес: https://mynameisnastasya.github.io/tango/gift-hunter/

## Автоматическое обновление (без импорта CSV/JSON)

Скачай расширение Tango Gift Hunter v0.3 для Chrome на Mac и включи его. Открой публичный эфир Tango Live и включи в расширении «Мониторинг». Затем открой веб-панель в **том же профиле Chrome** — она запросит сводку через `window.postMessage` и автоматически обновит локальную базу. Новые события отражаются при изменении данных расширения (если вкладка панели открыта) и при следующем открытии страницы. Нет необходимости экспортировать и загружать CSV/JSON.

**Важно:** публичный сайт сам не имеет доступа к `chrome.storage.local` расширения. Поэтому без обновлённого расширения v0.3 автопередача не работает.

## Что показывается

Публичные никнеймы, ссылки на профили Tango (когда их видно), количество наблюдаемых подарков, число эфиров и время активности. Статусы VIP/короны и заметки — ручные. Подарки **не подтверждают** реальные пополнения баланса Tango.

При повторных снимках события не суммируются повторно: агрегированные значения берутся по максимуму; ручные пометки сайта сохраняются. Сводка ограничена последними 3000 событиями расширения и 20 000 профилями в веб-панели.

## Ручной импорт (резерв)

Кнопка ручного импорта осталась только для старых CSV и резервных JSON. JSON-копию рекомендуем сохранять регулярно. Сайт хранит данные в `localStorage` конкретного браузера. Синхронизация между телефоном и Mac без облачного сервера не поддерживается.

## Безопасность

Данные передаются исключительно в текущую вкладку сайта `mynameisnastasya.github.io/tango/gift-hunter/`, без внешней API-загрузки или отправки на сервер. Расширение ограничено необходимыми адресами. Пароли Tango, SMS-коды, cookies, скрытые данные и платежи не используются. Мониторинг работает только пока открыта страница Tango, автоматического обхода эфиров нет. Не рассылает сообщения.
