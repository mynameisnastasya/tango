# Tango Gift Hunter — онлайн-панель

Веб-версия приложения для работы с публичными профилями Tango Live, доступная на GitHub Pages по пути `/gift-hunter/`.

## Возможности
- Импорт CSV, экспортированного из локального расширения Tango Gift Hunter.
- Импорт резервной копии JSON этой веб-версии.
- Поиск, сортировка по подаркам, отметки активности за 7 дней.
- Ручная проверка корон и VIP-статуса, заметки о профилях.
- Экспорт CSV и резервной копии JSON.

## Использование
1. На Mac открой расширение Gift Hunter, собери видимые события подарков в открытых эфирах.
2. В панели расширения выбери «Экспорт CSV».
3. Открой `https://mynameisnastasya.github.io/tango/gift-hunter/`.
4. Нажми «Импорт CSV / JSON» и выбери файл.
5. Нажми на карточку для проверки публичной ссылки и добавления заметок.
6. Регулярно сохраняй резервную копию JSON.

## Ограничения и приватность
- Это **статическая веб-панель**, не автономный круглосуточный парсер Tango.
- **Не подключается** к аккаунту Tango, не собирает данные с сайта без расширения, не проверяет пополнения, не отправляет сообщения.
- Информация сохраняется в `localStorage` текущего браузера. Она **не загружается** в GitHub или облачную базу и **не синхронизируется** между устройствами.
- Данные могут исчезнуть при очистке истории/данных сайта или использовании приватного режима; сохраняй резервные копии JSON.
- Знаки VIP/корон заполняются **вручную**, а показанные подарки не равнозначны денежным пополнениям.
- Поддерживаются только `https://tango.me/` и `https://www.tango.me/` в ссылках на профили.
- На GitHub Pages страница доступна всем, кто знает ссылку, но содержимое индивидуального `localStorage` не публикуется. Не храни пароли или иные секреты в заметках.
